# Screenshots

UI captures classified by **user role** and **function**. Captured at 1440×900 @2x.

## Classification

| Role | Function | File |
|------|----------|------|
| **Public** (unauthenticated) | Sign-in / role selection | `public/login.png` |
| **Officer** | Detection dashboard — KPI cards, anomaly flags | `officer/dashboard.png` |
| **Officer** | Beneficiary search — filters, paginated table, scores | `officer/beneficiaries.png` |
| **Admin** | System overview — officer/audit KPIs, admin-only nav | `admin/dashboard.png` |
| **Citizen** | Grievance portal home — submit / track entry points | `citizen/home.png` |

## Role differences (Officer vs Admin)

- Admin sees **System Overview** (vs Detection Dashboard), an **Admin** role pill, **Audit Log** nav item, **Admin mode** card, and extra KPIs (Active Officers, Audit Events).
- Officer nav omits Audit Log; KPIs focus on daily detection workload.
